# EEE383 Peer Evaluation System

A comprehensive peer evaluation platform for project-based courses at BRAC University.

## Features

### Students
- Google Workspace authentication (@g.bracu.ac.bd only)
- Student ID verification
- Anonymous peer evaluation
- Progress tracking
- One-time submission per teammate

### Admins
- Student management via CSV/Excel upload
- Configure evaluation periods
- View analytics and reports
- Export results
- Anonymous comments viewing

## Technology Stack

- **Frontend**: React, Material-UI
- **Backend**: Node.js, Express
- **Database**: PostgreSQL
- **Authentication**: Google OAuth 2.0

## Quick Start

1. Clone the repository
2. Setup backend: `cd backend && npm install`
3. Setup frontend: `cd frontend && npm install`
4. Configure database and environment variables
5. Run: `npm run dev` in both directories

## Deployment

The application can be deployed using:
- Docker
- Heroku
- Vercel (frontend)
- AWS
